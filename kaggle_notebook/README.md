# Kaggle companion notebook

Self-contained notebook that rebuilds the final model from the official competition files.

- Kaggle ID: `taeyangg4/spaceship-titanic-leak-free-tabpfn-fine-tuning-stack`
- Title: `Spaceship Titanic Leak-free TabPFN Fine-tuning Stack`
- Competition source: `spaceship-titanic`
- Accelerator: GPU (T4 or P100) · Internet: on (installs `tabpfn==9.1.0`, downloads TabPFN v3.5 weights)
- Secret: `TABPFN_TOKEN` (Prior Labs token; add it under Add-ons → Secrets — it is read into the environment and never printed)
- Runtime: about 1.5–2.5 h on a T4; `NB_FAST=1` runs a short smoke test (1 fold, few epochs)

What it does: builds the 23 baseline features, the frozen StratifiedGroupKFold(5, seed 42) folds and the four TabPFN v3.5 members (frozen, fine-tuned, fine-tune-then-refit, 100-epoch fine-tune predicted with 2 estimators), reports honest nested OOF accuracy against the values recorded in the project, and writes:

- `submission.csv` — 4-member stack (the public 0.82604 variant)
- `submission_stack3.csv` — 3-member stack (the CV-promoted champion, public 0.82020)

The notebook does not submit by itself. TabPFN fine-tuning is not bit-for-bit deterministic across GPUs, so numbers can differ slightly from the recorded ones.

The `.ipynb` is generated by `build_notebook.py`:

```bash
uv run python kaggle_notebook/build_notebook.py
kaggle kernels push -p kaggle_notebook
```

Before the notebook was built, its feature and fold code was checked cell by cell against `src/spaceship_titanic/` (identical frames, folds and early-stopping slices).
